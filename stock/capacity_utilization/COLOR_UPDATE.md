# 图表颜色优化

## 更新内容

将总表视图中的年份曲线颜色从相近色改为更有区分度的配色方案。

## 颜色对比

### 之前（5种颜色，对比度不够）

```
1. #ef4444 - 红色 🔴
2. #3b82f6 - 蓝色 🔵 
3. #10b981 - 绿色 🟢
4. #8b5cf6 - 紫色 🟣
5. #06b6d4 - 青色 🔵 ← 与蓝色相近
```

**问题**：蓝色(#3b82f6)和青色(#06b6d4)容易混淆

### 现在（7种颜色，区分度高）

```
1. #ef4444 - 红色 🔴
2. #f59e0b - 橙色 🟠 ← 更显眼
3. #10b981 - 绿色 🟢
4. #8b5cf6 - 紫色 🟣
5. #ec4899 - 粉红色 💗 ← 更明显
6. #14b8a6 - 青绿色 🩵 ← 新增
7. #f97316 - 深橙色 🟧 ← 新增
```

**优势**：
- ✅ 增加到7种颜色（支持更多年份）
- ✅ 去除相近的蓝色/青色组合
- ✅ 使用暖色调（橙色、粉色）增加对比
- ✅ 每种颜色都很容易区分

## 颜色方案说明

### 色彩分布
- **暖色系**：红色、橙色、深橙色、粉红色
- **冷色系**：绿色、紫色、青绿色

### 对比度
通过暖色和冷色交替排列，确保相邻颜色有明显区分：
1. 红（暖）
2. 橙（暖）
3. 绿（冷）
4. 紫（冷）
5. 粉（暖）
6. 青绿（冷）
7. 深橙（暖）

## 应用位置

### 1. 总表视图（renderGrid）
- 每年的产能利用率曲线使用不同颜色
- 支持显示多个年份（如2023-2025）
- 颜色循环使用（超过7年会重复）

### 2. 放大视图（showZoomChart）
- 与总表视图使用相同颜色
- 保持一致的视觉体验

## 固定颜色说明

某些曲线使用固定颜色，不受此更新影响：

### 同比曲线
- `#4ade80` - 浅绿色（固定）
- 或 `#10b981` - 绿色（某些视图）

### 环比曲线
- `#f59e0b` - 橙色（固定）

### 绝对值曲线
- `#3b82f6` - 蓝色（单指标视图）

## 视觉效果

### 总表视图
- 每个小图显示多年数据
- 不同年份的曲线颜色清晰可辨
- 鼠标悬停时更容易识别

### 趋势图视图
- 多行业对比时
- 图例清晰
- 便于选择和对比

## 使用建议

### 查看效果
```bash
open stock/html/capacity_utilization_chart.html
```

### 切换视图
1. 点击"总表"按钮
2. 观察不同年份的曲线颜色
3. 使用过滤功能查看特定行业

### 自定义颜色
如需修改颜色，编辑 `capacity_utilization_chart.html`：

```javascript
// 第332行和第662行
const colors = [
  '#ef4444',  // 红色 - 可替换为其他颜色
  '#f59e0b',  // 橙色
  '#10b981',  // 绿色
  '#8b5cf6',  // 紫色
  '#ec4899',  // 粉红色
  '#14b8a6',  // 青绿色
  '#f97316'   // 深橙色
];
```
