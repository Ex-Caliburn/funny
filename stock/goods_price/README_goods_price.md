# 流通领域重要生产资料市场价格变动情况数据可视化系统

## 📊 系统概述

流通领域重要生产资料市场价格变动情况数据可视化系统是一个专门用于分析和展示中国重要生产资料市场价格变动的交互式图表工具。系统支持50种生产资料的价格趋势分析、环比和同比增长率计算。

## 📈 数据来源

- **数据发布机构**: 中国国家统计局
- **发布频率**: 每月三次（上旬、中旬、下旬）
- **数据范围**: 2024年1月至今
- **商品数量**: 50种重要生产资料
- **数据维度**: 本期价格、比上期价格涨跌、涨跌幅

## 🎯 功能特性

### 1. 商品价格趋势分析

- 选择任意商品查看详细价格趋势
- 显示本期价格、环比、同比增长率
- 支持时间范围筛选

### 2. 类别对比分析

- 按类别（黑色金属、有色金属、化工等）分组展示
- 同类商品价格走势对比
- 支持多商品同时显示

### 3. 涨跌幅分析

- 按涨跌幅排序
- 识别价格异常波动
- 历史涨跌幅趋势

### 4. 数据网格视图

- 表格形式展示所有商品
- 支持按类别、名称、价格筛选
- 可导出数据

## 📅 数据处理特点

### 时间格式

- **发布日期**: YYYY-MM-DD（如 2025-10-23）
- **期间标识**: 上旬/中旬/下旬
- **数据频率**: 每月3次

### 价格计算

- **本期价格**: 当前市场价格（元）
- **环比变动**: 与上期价格对比（元）
- **涨跌幅**: 环比变动百分比（%）
- **同比增长率**: 自动计算（基于历史数据）

### 数据清洗

- 指标名称标准化
- 去除空格和特殊字符
- 统一单位格式
- 处理缺失值

## 📈 使用指南

### 启动系统

```bash
# 1. 爬取最新数据
npm run crawl:goods 3

# 2. 解析数据（自动运行，也可手动）
npm run goods:parse

# 3. 启动可视化服务
npm run serve:goods

# 4. 访问地址
http://localhost:8081/html/goods_price_chart.html
```

### 操作说明

1. **选择商品**: 从下拉菜单选择要查看的商品
2. **切换类别**: 点击类别标签快速筛选
3. **调整时间**: 使用时间范围选择器
4. **查看详情**: 悬停在数据点查看详细信息
5. **导出数据**: 点击导出按钮保存数据

## 🔄 数据更新流程

1. **爬取新数据**: `npm run crawl:goods 1`
2. **自动解析**: 系统自动运行 `goods_price_parse.js`
3. **生成JSON**: 更新 `goods_price_cleaned.json`
4. **刷新页面**: 重新加载图表查看最新数据
