# 能源数据可视化系统

## 🔋 系统概述

能源数据可视化系统是一个专门用于分析中国能源生产数据的交互式图表工具。系统支持多种能源指标的趋势分析，包括传统能源和新能源的生产情况及增长趋势。

## 📊 数据指标

### 主要生产指标

- **原煤**：月度产量（亿吨）
- **原油**：月度产量（万吨）
- **原油加工**：月度加工量（万吨）
- **天然气**：月度产量（亿立方米）
- **发电量**：月度发电量（亿千瓦时）

### 发电结构指标

- **火电**：同比增速（%）
- **水电**：同比增速（%）
- **核电**：同比增速（%）
- **风电**：同比增速（%）
- **太阳能发电**：同比增速（%）

### 进口数据（仅数据展示，不在主要图表中显示）

- **原煤进口**、**原油进口**、**天然气进口**

## 🎯 功能特性

### 1. 单指标详细分析

- 选择任意指标查看详细趋势
- 同时显示：当月值、环比增长率、同比增长率
- 支持指标名称一键复制

### 2. 发电量专用分析

- 专门展示5种发电方式的同比增速对比
- 清晰的颜色区分和图例标识
- 支持数据缩放和时间范围选择

### 3. 总表网格视图

- 5个主要指标的小图表网格展示
- 支持关键字过滤
- 可控制显示：环比曲线、同比曲线、历史年份
- 每个小图支持放大查看

### 4. 多指标趋势对比

- 主要指标的合并曲线图
- 支持图例选择（显示/隐藏特定指标）
- 全选/反选功能
- 数据缩放和内部缩放支持

## 📅 数据处理特点

### 时间处理

- **标准月份**：2025-08, 2025-07 等格式
- **合并月份**：2025-1-2 表示1-2月合并数据，在图表中显示为"1-2月"
- **历史格式**：2023-07-17 等带日期的格式自动提取月份

### 数据计算

- **环比增长率**：自动计算月度环比增长
- **同比增长率**：从原始数据中提取或计算
- **缺失数据处理**：null值在图表中显示为断点

## 🎨 界面设计

### 视觉主题

- **深色主题**：适合长时间数据分析
- **蓝色主调**：专业的数据可视化风格
- **响应式设计**：适配不同屏幕尺寸

### 交互体验

- **悬停提示**：详细的数据提示信息
- **图例控制**：点击图例显示/隐藏数据系列
- **缩放功能**：滑块缩放和鼠标滚轮缩放

## 📈 使用指南

### 启动系统

```bash
# 解析最新数据
npm run energy:parse

# 启动服务
npm run serve:energy

# 访问地址
http://localhost:8086/html/energy_chart.html
```

### 操作说明

1. **切换视图**：点击顶部tab切换不同视图模式
2. **过滤数据**：在总表和趋势图中使用搜索框过滤指标
3. **控制显示**：使用按钮控制环比、同比曲线和历史年份显示
4. **放大查看**：点击小图表右上角的🔍按钮放大查看
5. **数据缩放**：使用底部滑块或鼠标滚轮缩放时间范围

## 🔄 数据更新流程

1. **获取新数据**：将新的Excel文件放入 `stock/energy/` 目录
2. **更新解析脚本**：如需要，修改 `scripts/tools/energy_parser.js` 中的文件列表
3. **运行解析**：执行 `npm run energy:parse`
4. **验证结果**：检查生成的 `energy_cleaned.json` 文件
5. **刷新页面**：重新加载图表页面查看更新

## 📋 数据质量说明

- **数据来源**：国家统计局等官方统计部门
- **更新频率**：通常月度更新
- **数据完整性**：部分月份可能存在数据缺失
- **单位统一**：所有数据已按标准单位处理
