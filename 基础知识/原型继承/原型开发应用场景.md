# 原型开发应用场景

## 前言

原型继承是 JavaScript 中实现代码复用和扩展的重要机制。在前端开发中，原型开发有很多实际应用场景，从组件库开发到状态管理，都能看到原型继承的身影。

## 1. 组件库开发

### 基础组件封装

```js
// 基础按钮组件
function BaseButton(text, onClick) {
    this.text = text;
    this.onClick = onClick;
}

BaseButton.prototype.render = function() {
    const button = document.createElement('button');
    button.textContent = this.text;
    button.addEventListener('click', this.onClick);
    return button;
};

// 扩展为不同样式的按钮
function PrimaryButton(text, onClick) {
    BaseButton.call(this, text, onClick);
}

PrimaryButton.prototype = Object.create(BaseButton.prototype);
PrimaryButton.prototype.constructor = PrimaryButton;

PrimaryButton.prototype.render = function() {
    const button = BaseButton.prototype.render.call(this);
    button.className = 'btn btn-primary';
    return button;
};

// 使用示例
const primaryBtn = new PrimaryButton('点击我', () => alert('Hello!'));
document.body.appendChild(primaryBtn.render());
```

### 组件继承的优势

- **代码复用**：基础功能在父类中实现
- **样式扩展**：子类可以添加特定的样式和行为
- **统一接口**：所有按钮组件都有相同的 `render` 方法

## 2. 插件系统开发

### 可扩展的插件架构

```js
// 基础插件类
function Plugin() {
    this.name = 'base';
    this.version = '1.0.0';
}

Plugin.prototype.init = function() {
    console.log('Plugin initialized');
};

Plugin.prototype.destroy = function() {
    console.log('Plugin destroyed');
};

// 具体插件实现
function ImagePlugin() {
    Plugin.call(this);
    this.name = 'image';
}

ImagePlugin.prototype = Object.create(Plugin.prototype);
ImagePlugin.prototype.constructor = ImagePlugin;

ImagePlugin.prototype.init = function() {
    Plugin.prototype.init.call(this);
    console.log('Image plugin loaded');
};

// 插件管理器
function PluginManager() {
    this.plugins = [];
}

PluginManager.prototype.register = function(plugin) {
    if (plugin instanceof Plugin) {
        this.plugins.push(plugin);
        plugin.init();
    }
};

// 使用示例
const manager = new PluginManager();
const imagePlugin = new ImagePlugin();
manager.register(imagePlugin);
```

### 插件系统的特点

- **统一接口**：所有插件都继承自基础 Plugin 类
- **生命周期管理**：统一的 init 和 destroy 方法
- **类型检查**：通过 instanceof 确保插件类型正确

## 3. 事件系统

### 自定义事件发射器

```js
function EventEmitter() {
    this.events = {};
}

EventEmitter.prototype.on = function(event, callback) {
    if (!this.events[event]) {
        this.events[event] = [];
    }
    this.events[event].push(callback);
};

EventEmitter.prototype.emit = function(event, data) {
    if (this.events[event]) {
        this.events[event].forEach(callback => callback(data));
    }
};

// 继承事件系统
function UserManager() {
    EventEmitter.call(this);
    this.users = [];
}

UserManager.prototype = Object.create(EventEmitter.prototype);
UserManager.prototype.constructor = UserManager;

UserManager.prototype.addUser = function(user) {
    this.users.push(user);
    this.emit('userAdded', user);
};

// 使用示例
const userManager = new UserManager();
userManager.on('userAdded', (user) => {
    console.log('New user added:', user);
});

userManager.addUser({ name: 'John', age: 25 });
```

### 事件系统的优势

- **解耦**：组件间通过事件通信，降低耦合度
- **扩展性**：可以动态添加和移除事件监听器
- **复用性**：任何类都可以继承事件功能

## 4. 数据模型层

### 基础模型类

```js
function BaseModel(data = {}) {
    this.data = data;
    this.observers = [];
}

BaseModel.prototype.set = function(key, value) {
    this.data[key] = value;
    this.notify(key, value);
};

BaseModel.prototype.get = function(key) {
    return this.data[key];
};

BaseModel.prototype.observe = function(callback) {
    this.observers.push(callback);
};

BaseModel.prototype.notify = function(key, value) {
    this.observers.forEach(callback => callback(key, value));
};

// 用户模型
function UserModel(userData) {
    BaseModel.call(this, userData);
}

UserModel.prototype = Object.create(BaseModel.prototype);
UserModel.prototype.constructor = UserModel;

UserModel.prototype.updateProfile = function(profile) {
    this.set('profile', profile);
};

// 使用示例
const user = new UserModel({ name: 'Alice' });
user.observe((key, value) => {
    console.log(`${key} changed to:`, value);
});

user.updateProfile({ age: 30, city: 'Beijing' });
```

### 数据模型的特点

- **响应式**：数据变化时自动通知观察者
- **统一接口**：所有模型都有相同的 get/set 方法
- **观察者模式**：支持数据变化的监听

## 5. 路由系统

### 基础路由类

```js
function Router() {
    this.routes = {};
    this.currentRoute = null;
}

Router.prototype.route = function(path, handler) {
    this.routes[path] = handler;
};

Router.prototype.navigate = function(path) {
    if (this.routes[path]) {
        this.currentRoute = path;
        this.routes[path]();
    }
};

// 扩展路由功能
function AdvancedRouter() {
    Router.call(this);
    this.middlewares = [];
}

AdvancedRouter.prototype = Object.create(Router.prototype);
AdvancedRouter.prototype.constructor = AdvancedRouter;

AdvancedRouter.prototype.use = function(middleware) {
    this.middlewares.push(middleware);
};

AdvancedRouter.prototype.navigate = function(path) {
    // 执行中间件
    this.middlewares.forEach(middleware => middleware(path));
    
    // 调用父类方法
    Router.prototype.navigate.call(this, path);
};

// 使用示例
const router = new AdvancedRouter();
router.use((path) => console.log('Navigating to:', path));

router.route('/home', () => console.log('Home page'));
router.route('/about', () => console.log('About page'));

router.navigate('/home');
```

### 路由系统的优势

- **中间件支持**：可以在路由切换时执行额外逻辑
- **功能扩展**：子类可以添加新的路由功能
- **代码复用**：基础路由逻辑在父类中实现

## 6. 状态管理

### 简单状态管理器

```js
function Store(initialState = {}) {
    this.state = initialState;
    this.subscribers = [];
}

Store.prototype.getState = function() {
    return this.state;
};

Store.prototype.dispatch = function(action) {
    this.state = { ...this.state, ...action };
    this.subscribers.forEach(callback => callback(this.state));
};

Store.prototype.subscribe = function(callback) {
    this.subscribers.push(callback);
};

// 用户状态管理
function UserStore() {
    Store.call(this, { users: [], currentUser: null });
}

UserStore.prototype = Object.create(Store.prototype);
UserStore.prototype.constructor = UserStore;

UserStore.prototype.addUser = function(user) {
    const users = [...this.state.users, user];
    this.dispatch({ users });
};

// 使用示例
const userStore = new UserStore();
userStore.subscribe((state) => {
    console.log('State updated:', state);
});

userStore.addUser({ name: 'Bob', age: 28 });
```

### 状态管理的特点

- **响应式更新**：状态变化时自动通知订阅者
- **不可变更新**：每次更新都创建新的状态对象
- **统一接口**：所有 store 都有相同的 subscribe/dispatch 方法

## 7. 工具函数库

### 基础工具类

```js
function Utils() {}

Utils.prototype.formatDate = function(date) {
    return date.toLocaleDateString();
};

Utils.prototype.formatCurrency = function(amount) {
    return `$${amount.toFixed(2)}`;
};

// 扩展工具类
function AdvancedUtils() {
    Utils.call(this);
}

AdvancedUtils.prototype = Object.create(Utils.prototype);
AdvancedUtils.prototype.constructor = AdvancedUtils;

AdvancedUtils.prototype.formatDate = function(date, format = 'short') {
    if (format === 'long') {
        return date.toLocaleDateString('en-US', {
            weekday: 'long',
            year: 'numeric',
            month: 'long',
            day: 'numeric'
        });
    }
    return Utils.prototype.formatDate.call(this, date);
};

// 使用示例
const utils = new AdvancedUtils();
console.log(utils.formatDate(new Date())); // 短格式
console.log(utils.formatDate(new Date(), 'long')); // 长格式
console.log(utils.formatCurrency(123.456)); // $123.46
```

### 工具库的优势

- **功能扩展**：子类可以添加新的工具方法
- **向后兼容**：保持原有方法的同时添加新功能
- **统一命名空间**：所有工具方法都在同一个对象上

## 8. 表单验证系统

### 基础验证器

```js
function Validator() {
    this.rules = {};
}

Validator.prototype.addRule = function(field, rule) {
    if (!this.rules[field]) {
        this.rules[field] = [];
    }
    this.rules[field].push(rule);
};

Validator.prototype.validate = function(data) {
    const errors = {};
    
    Object.keys(this.rules).forEach(field => {
        if (data[field]) {
            this.rules[field].forEach(rule => {
                if (!rule.validate(data[field])) {
                    if (!errors[field]) errors[field] = [];
                    errors[field].push(rule.message);
                }
            });
        }
    });
    
    return errors;
};

// 具体验证规则
function RequiredRule() {
    this.message = 'This field is required';
}

RequiredRule.prototype.validate = function(value) {
    return value && value.toString().trim().length > 0;
};

// 使用示例
const validator = new Validator();
validator.addRule('name', new RequiredRule());

const errors = validator.validate({ name: '' });
console.log(errors); // { name: ['This field is required'] }
```

### 验证系统的特点

- **规则可扩展**：可以轻松添加新的验证规则
- **统一接口**：所有验证规则都有相同的 validate 方法
- **错误聚合**：可以收集多个字段的多个错误

## 9. 缓存系统

### 基础缓存类

```js
function Cache() {
    this.storage = new Map();
    this.maxSize = 100;
}

Cache.prototype.set = function(key, value) {
    if (this.storage.size >= this.maxSize) {
        const firstKey = this.storage.keys().next().value;
        this.storage.delete(firstKey);
    }
    this.storage.set(key, value);
};

Cache.prototype.get = function(key) {
    return this.storage.get(key);
};

// LRU 缓存实现
function LRUCache() {
    Cache.call(this);
    this.accessOrder = [];
}

LRUCache.prototype = Object.create(Cache.prototype);
LRUCache.prototype.constructor = LRUCache;

LRUCache.prototype.set = function(key, value) {
    // 更新访问顺序
    this.accessOrder = this.accessOrder.filter(k => k !== key);
    this.accessOrder.push(key);
    
    Cache.prototype.set.call(this, key, value);
};

LRUCache.prototype.get = function(key) {
    const value = Cache.prototype.get.call(this, key);
    if (value !== undefined) {
        // 更新访问顺序
        this.accessOrder = this.accessOrder.filter(k => k !== key);
        this.accessOrder.push(key);
    }
    return value;
};
```

## 10. 网络请求封装

### 基础请求类

```js
function BaseRequest() {
    this.baseURL = '';
    this.headers = {};
}

BaseRequest.prototype.request = function(url, options = {}) {
    const fullURL = this.baseURL + url;
    const requestOptions = {
        headers: { ...this.headers, ...options.headers },
        ...options
    };
    
    return fetch(fullURL, requestOptions);
};

// HTTP 客户端
function HttpClient() {
    BaseRequest.call(this);
    this.baseURL = 'https://api.example.com';
    this.headers = {
        'Content-Type': 'application/json'
    };
}

HttpClient.prototype = Object.create(BaseRequest.prototype);
HttpClient.prototype.constructor = HttpClient;

HttpClient.prototype.get = function(url) {
    return this.request(url, { method: 'GET' });
};

HttpClient.prototype.post = function(url, data) {
    return this.request(url, {
        method: 'POST',
        body: JSON.stringify(data)
    });
};
```

## 总结

### 原型开发的核心优势

1. **代码复用**
   - 避免重复编写相似代码
   - 基础功能在父类中实现
   - 子类专注于扩展功能

2. **扩展性**
   - 易于添加新功能
   - 支持运行时动态修改
   - 灵活的继承关系

3. **维护性**
   - 统一的接口和实现
   - 集中的逻辑管理
   - 清晰的代码结构

4. **灵活性**
   - 支持多重继承
   - 动态原型修改
   - 运行时行为调整

### 适用场景

- **需要代码复用的项目**
- **组件库和框架开发**
- **插件系统架构**
- **工具函数库**
- **状态管理系统**
- **事件处理系统**

### 注意事项

1. **原型链过长**：避免过深的继承层次
2. **性能考虑**：原型链查找有一定性能开销
3. **调试困难**：原型链可能使调试变得复杂
4. **内存泄漏**：注意循环引用的处理

原型开发是 JavaScript 中实现面向对象编程的重要方式，合理使用可以大大提高代码的可维护性和扩展性。
