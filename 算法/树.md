# 树

## 前言

树的三种遍历，前序、中序、后序，是指以根节点为视角定义的。
如果根节点先被访问，即根-左-右，则是前序遍历；
如果根节点是中间被访问，即左-根-右，则是中序遍历；
如果根节点是最后被访问，即左-右-根，则是后序遍历。

典型用途
前序：复制/序列化树；构建表达式的前缀式
中序：二叉搜索树（BST）中序结果是递增序列
后序：删除/释放树（先处理子树再处理父）；构建表达式的后缀式

示例（结构）
树：
根 A，左子树 B（左 D，右 E），右子树 C（右 F）
结果：
前序：A B D E C F
中序：D B E A C F
后序：D E B F C A

### 遍历代码模板（JavaScript）

```javascript
// 二叉树节点结构假定为：{ val, left, right }

function preOrder(root, res = []) { // 前序：根-左-右
  if (!root) return res
  res.push(root.val)
  preOrder(root.left, res)
  preOrder(root.right, res)
  return res
}

function inOrder(root, res = []) { // 中序：左-根-右
  if (!root) return res
  inOrder(root.left, res)
  res.push(root.val)
  inOrder(root.right, res)
  return res
}

function postOrder(root, res = []) { // 后序：左-右-根
  if (!root) return res
  postOrder(root.left, res)
  postOrder(root.right, res)
  res.push(root.val)
  return res
}
```

### 高度和深度

树的高度 height 和深度 depth 是两个非常重要的概念，比如 Leetcode 104 和 111 就是专门求树的高度的。

而这两个概念是相反方向的，大体上呢，

高度是从当前节点到叶子 🍃 节点的；
深度是从当前节点到根 🌲 节点的。

分割线就是地平线，之上是高度，之下是深度
