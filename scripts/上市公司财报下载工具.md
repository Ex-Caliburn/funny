# 📥 上市公司财报下载工具

> 从巨潮资讯网（中国证监会指定信息披露网站）自动下载A股上市公司财务报告

## 🎯 功能特点

- ✅ **权威数据源**：巨潮资讯网（www.cninfo.com.cn）
- ✅ **全类型支持**：年报、半年报、季报（Q1、Q3）
- ✅ **批量下载**：支持单公司和多公司批量下载
- ✅ **智能命名**：自动规范文件命名（公司名+年份+报告类型.pdf）
- ✅ **断点续传**：已下载文件自动跳过
- ✅ **进度显示**：实时显示下载进度

---

## 🚀 快速开始

### 1️⃣ 下载所有报告（年报+半年报+季报）

```bash
node download_all_reports.js --code 600348 --name 华阳股份 --years 2023 --type all
```

### 2️⃣ 只下载年报

```bash
node download_all_reports.js --code 600348 --name 华阳股份 --start 2021 --end 2023 --type annual
```

### 3️⃣ 批量下载多家公司

```bash
# 编辑 batch_config_example.json 后运行
node batch_download_reports.js --config batch_config_example.json
```

## 📋 参数说明

### 基本参数

| 参数 | 说明 | 必填 | 示例 |
|------|------|------|------|
| `--code` | 股票代码（6位数字） | ✅ | `600348` |
| `--name` | 公司名称 | ✅ | `华阳股份` |
| `--years` | 年份（逗号分隔） | * | `2021,2022,2023` |
| `--start` | 起始年份 | * | `2021` |
| `--end` | 结束年份 | * | `2023` |
| `--type` | 报告类型 | ✅ | `all` / `annual` / `semi` / `quarterly` |
| `--output` | 输出目录（可选） | ❌ | `./reports` |

> 注：`--years` 和 `--start/--end` 二选一

### 报告类型（--type 参数）

| 参数值 | 说明 | 下载内容 |
|--------|------|----------|
| `all` | 所有报告 | 年报 + 半年报 + Q1 + Q3 |
| `annual` | 年度报告 | 仅年报 |
| `semi` | 半年度报告 | 仅半年报 |
| `quarterly` | 季度报告 | Q1 + Q3 |
| `q1` | 第一季度 | 仅Q1 |
| `q3` | 第三季度 | 仅Q3 |

> 💡 **提示**：中国A股没有Q2和Q4独立季报
>
> - Q2数据在半年报中披露
> - Q4数据在年报中披露

## 💡 使用场景示例

### 场景1：完整财务分析（下载所有报告）

```bash

  --code 600348 \
  --name 华阳股份 \
  --start 2021 \
  --end 2023 \
  --type all
```

```
华阳股份2021年第三季度报告.pdf
... (2022, 2023 同样)
```

### 场景2：长期价值投资（只下载年报）

```bash

```

### 场景3：追踪季度变化（只下载季报）


```json

    { "code": "000858", "name": "五粮液" },

  "years": [2020, 2021, 2022, 2023]
```

运行：

```bash
node batch_download_reports.js --config 白酒行业.json
```

## ⚠️ 注意事项

### 1. 报告发布时间

- **年报**：通常在次年 **3-4月** 公布
- **半年报**：当年 **7-8月** 公布
- **季报**：Q1在4月，Q3在10月
- **建议**：下载当前年份前一年及更早的报告

### 2. 网络要求

- 需要能够访问 `www.cninfo.com.cn`
- 建议在网络稳定时下载
- 工具已内置延迟，避免过快请求

### 3. 股票代码规则

- **上交所**：6开头（如：600348、601318）
- **深交所**：0或3开头（如：000001、002594、300750）
- 必须是完整的6位数字

### 4. 文件大小

| 报告类型 | 典型大小 |
|---------|---------|
| 年报 | 3-8MB |
| 半年报 | 2-5MB |
| 季报 | 300KB-1MB |

## 🐛 常见问题

### Q1: 提示"未找到报告"？

**原因**：

- 该年份报告尚未发布
- 股票代码或公司名称错误
- 公司在该年份尚未上市

**解决**：

- 检查股票代码是否正确
- 确认报告是否已发布
- 尝试下载更早年份的报告

### Q2: 下载速度慢？

**原因**：

- 巨潮资讯网服务器繁忙
- 报告文件较大（5-20MB）
- 网络不稳定

**解决**：

- 在非交易时间（晚上或周末）下载
- 使用更稳定的网络
- 耐心等待

### Q3: 如何查找股票代码？

**方法**：

1. 访问 [东方财富网](https://www.eastmoney.com/) 搜索公司名
2. 访问 [巨潮资讯网](http://www.cninfo.com.cn/) 搜索
3. 使用股票软件（同花顺、东方财富等）查询
4. 百度搜索"公司名 股票代码"

### Q4: 为什么没有第二和第四季度报告？

**A**: 中国A股市场规定：

- Q2数据在半年报中披露
- Q4数据在年报中披露
- 所以只有Q1和Q3独立季报

### Q5: 文件已存在如何重新下载？

删除已存在的文件后重新运行命令，或直接删除对应公司的整个文件夹。
