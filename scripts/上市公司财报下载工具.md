# 📥 上市公司财报下载工具

> 从巨潮资讯网（中国证监会指定信息披露网站）自动下载A股上市公司财务报告

## 🎯 功能特点

- ✅ **权威数据源**：巨潮资讯网（www.cninfo.com.cn）
- ✅ **全类型支持**：年报、半年报、季报（Q1、Q3）、生产经营数据公告
- ✅ **批量下载**：支持单公司和多公司批量下载
- ✅ **智能命名**：自动规范文件命名（公司名+年份+报告类型.pdf）
- ✅ **灵活关键词**：支持自定义关键词匹配任意类型公告
- ✅ **断点续传**：已下载文件自动跳过
- ✅ **进度显示**：实时显示下载进度

---

## 🚀 快速开始

### 1️⃣ 下载所有报告（年报+半年报+季报）

```bash
node download_all_reports.js --code 600348 --name 华阳股份 --years 2023 --type all
```

### 2️⃣ 只下载年报

```bash
node download_all_reports.js --code 600348 --name 华阳股份 --start 2021 --end 2023 --type annual
```

### 3️⃣ 批量下载多家公司

```bash
# 编辑 batch_config_example.json 后运行
node batch_download_reports.js --config batch_config_example.json
```

### 4️⃣ 下载生产经营数据公告

```bash
# 下载山煤国际2024年生产经营数据公告（使用默认关键词）
node download_all_reports.js --code 600546 --name 山煤国际 --years 2024 --type production

# 自定义关键词
node download_all_reports.js --code 600546 --name 山煤国际 --years 2024 --type production --keywords "生产经营数据公告"
```

### 5️⃣ 同时下载多个报告类型 ⭐ 新功能

```bash
# 同时下载年报和运营报告（推荐）
node download_all_reports.js --code 600348 --name 华阳股份 --years 2023 --types annual,production --keywords "生产经营数据公告"

# 同时下载多个类型
node download_all_reports.js --code 600348 --name 华阳股份 --years 2023 --types annual,semi,production --keywords "生产经营数据公告"
```

## 📋 参数说明

### 基本参数

| 参数 | 说明 | 必填 | 示例 |
|------|------|------|------|
| `--code` | 股票代码（6位数字） | ✅ | `600348` |
| `--name` | 公司名称 | ✅ | `华阳股份` |
| `--years` | 年份（逗号分隔） | * | `2021,2022,2023` |
| `--start` | 起始年份 | * | `2021` |
| `--end` | 结束年份 | * | `2023` |
| `--type` | 报告类型（单个） | ✅ | `all` / `annual` / `semi` / `quarterly` / `production` |
| `--types` | 报告类型（多个，逗号分隔）⭐ 新功能 | ✅ | `annual,production` |
| `--keywords` | 自定义关键词（逗号分隔） | ❌ | `生产经营数据公告` |
| `--output` | 输出目录（可选） | ❌ | `./reports` |

> 注：`--years` 和 `--start/--end` 二选一
>
> 🆕 **新功能**：支持 `--types` 参数同时下载多个报告类型，如 `--types annual,production` 可同时下载年报和运营报告

### 报告类型（--type 参数）

| 参数值 | 说明 | 下载内容 |
|--------|------|----------|
| `all` | 所有报告 | 年报 + 半年报 + Q1 + Q3 |
| `annual` | 年度报告 | 仅年报 |
| `semi` | 半年度报告 | 仅半年报 |
| `quarterly` | 季度报告 | Q1 + Q3 |
| `q1` | 第一季度 | 仅Q1 |
| `q3` | 第三季度 | 仅Q3 |
| `production` | 生产经营数据公告 | 自定义关键词匹配的所有公告 |

> 💡 **提示**：中国A股没有Q2和Q4独立季报
>
> - Q2数据在半年报中披露
> - Q4数据在年报中披露

> 🆕 **新功能**：`production` 类型支持灵活的关键词匹配
>
> - 可用于下载生产经营数据公告、董事会决议、股东大会决议等任意类型公告
> - 默认关键词：`生产经营数据公告`
> - 可通过 `--keywords` 参数自定义关键词

## 📊 报告时间说明

| 报告类型 | 报告期 | 发布时间 | 详细程度 |
|---------|--------|----------|----------|
| 第一季度报告 | 1-3月 | 4月 | 简要（30-50页） |

- 📅 2024年12月：2024年年报尚未发布

## ⚠️ 注意事项

### 1. 报告发布时间

- **年报**：通常在次年 **3-4月** 公布
- **半年报**：当年 **7-8月** 公布
- **季报**：Q1在4月，Q3在10月
- **建议**：下载当前年份前一年及更早的报告

### 2. 网络要求

- 需要能够访问 `www.cninfo.com.cn`
- 建议在网络稳定时下载
- 工具已内置延迟，避免过快请求

### 3. 股票代码规则

- **上交所**：6开头（如：600348、601318）
- **深交所**：0或3开头（如：000001、002594、300750）
- 必须是完整的6位数字

### 4. 文件大小

| 报告类型 | 典型大小 |
|---------|---------|
| 年报 | 3-8MB |
| 半年报 | 2-5MB |
| 季报 | 300KB-1MB |
| 生产经营数据公告 | 50KB-500KB |

## 🐛 常见问题

### Q1: 提示"未找到报告"？

**原因**：

- 该年份报告尚未发布
- 股票代码或公司名称错误
- 公司在该年份尚未上市

**解决**：

- 检查股票代码是否正确
- 确认报告是否已发布
- 尝试下载更早年份的报告

### Q2: 下载速度慢？

**原因**：

- 巨潮资讯网服务器繁忙
- 报告文件较大（5-20MB）
- 网络不稳定

**解决**：

- 在非交易时间（晚上或周末）下载
- 使用更稳定的网络
- 耐心等待

### Q3: 如何查找股票代码？

**方法**：

1. 访问 [东方财富网](https://www.eastmoney.com/) 搜索公司名
2. 访问 [巨潮资讯网](http://www.cninfo.com.cn/) 搜索
3. 使用股票软件（同花顺、东方财富等）查询
4. 百度搜索"公司名 股票代码"

### Q4: 为什么没有第二和第四季度报告？

**A**: 中国A股市场规定：

- Q2数据在半年报中披露
- Q4数据在年报中披露
- 所以只有Q1和Q3独立季报

### Q5: 文件已存在如何重新下载？

删除已存在的文件后重新运行命令，或直接删除对应公司的整个文件夹。

### Q6: 如何下载生产经营数据公告？

**步骤**：

1. 先在巨潮资讯网查看公告标题，确认关键词
2. 使用 `--type production` 参数
3. 通过 `--keywords` 指定关键词（可选，默认为"生产经营数据公告"）

**示例**：

```bash
# 使用默认关键词
node download_all_reports.js --code 600546 --name 山煤国际 --years 2024 --type production

# 自定义关键词
node download_all_reports.js --code 600546 --name 山煤国际 --years 2024 --type production --keywords "月度数据"

# 多个关键词（任一匹配即可）
node download_all_reports.js --code 600546 --name 山煤国际 --years 2024 --type production --keywords "生产经营数据公告,月度数据"
```

### Q7: 为什么搜索不到生产经营数据公告？

**可能原因**：

1. 关键词不匹配 - 不同公司的公告标题格式可能不同
2. 该公司不发布此类公告
3. 该年度尚未发布

**解决方法**：

1. 访问巨潮资讯网，搜索该公司，查看实际公告标题
2. 根据实际标题调整 `--keywords` 参数
3. 尝试更宽泛的关键词（如"数据"、"月度"等）
4. **如果找不到独立公告，数据可能在定期报告中**（见下方"数据获取渠道汇总"章节）

## 📊 数据获取渠道汇总

### 🎯 当找不到独立生产经营数据公告时

某些公司可能不发布独立的生产经营数据公告，但数据会在定期报告中披露。以下是完整的数据获取渠道：

---

### 📈 方案1：从定期报告中提取（推荐）⭐

**优势**：

- ✅ **最权威** - 经过审计的官方数据
- ✅ **最详细** - 包含完整的经营分析
- ✅ **最可靠** - 数据准确性有保障

**操作步骤**：

```bash
# 下载所有定期报告
node download_all_reports.js \
  --code 600546 \
  --name 山煤国际 \
  --years 2024 \
  --type all

# 使用解析工具提取数据（如果有对应工具）
node scripts/shanmei_report_parse.js
```

**数据位置**：

| 报告类型 | 数据位置 |
|---------|---------|
| **年报/半年报** | 第三节 管理层讨论与分析 → 主营业务分析 → 生产情况/销售情况/主要产品产销量 |
| **季报** | 经营情况讨论与分析 → 主要经营数据 |

**示例：山煤国际数据发布情况**

| 年份 | 独立生产经营数据公告 | 定期报告 | 数据源 |
|------|-------------------|---------|--------|
| 2025 | ✅ 季度数据（Q1/Q2/Q3） | ✅ | 东方财富网 |
| 2024 | ❌ 无 | ✅ 年报/季报 | 巨潮资讯网 |
| 2023 | ❌ 无 | ✅ 年报/季报 | 巨潮资讯网 |
| 2022 | ✅ 1-2月经营情况 | ✅ | 巨潮资讯网 |

**结论**：

- 2025年开始发布独立的季度生产经营数据公告
- 2024年及之前，数据主要在定期报告中披露
- 2022年曾短暂发布过月度数据，后停止
