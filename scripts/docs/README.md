**特别说明：**
港股下载与 A 股有以下不同：
- 数据来源：香港交易所（hkexnews.hk）
- 股票代码：5位数字（如 00883）
- 报告格式：主要为 PDF 格式
- 搜索机制：需要使用特定的搜索参数
- 框架特点：使用JSF框架，需要特殊处理

## 🔍 调试文件说明

### 调试模式

启用港股下载调试模式：

```bash
# 设置环境变量
export DEBUG_HK=1

# 运行下载脚本
node scripts/stock-reports/download_hk_reports.js --code 00883 --name 中国海洋石油 --years 2024
```

启用后会：
1. 保存 HTML 响应到 `hk_debug_response.html`
2. 输出详细的调试日志
3. 显示请求和响应的详细信息

### 调试文件用途

**hk_debug_page.html**
- 保存的完整搜索页面HTML
- 用于分析页面结构
- 帮助调试选择器

**hk_debug_response.html**
- API 响应的原始HTML
- 用于调试数据解析
- 查看返回的报告列表

**hk_debug_screenshot.png**
- 港股搜索页面的截图
- 用于参考页面布局
- 帮助理解搜索流程
