# 港股业绩报下载 - 测试指南

## 📋 测试前准备

### 1. 检查Python环境

```bash
# 检查Python版本（需要3.7+）
python3 --version

# 如果提示找不到python3，尝试
which python3
```

### 2. 安装依赖

```bash
# 安装Playwright和相关库
pip3 install playwright aiohttp aiofiles

# 安装浏览器驱动（首次需要）
playwright install chromium
```

**注意**：`playwright install chromium` 会下载约170MB的Chromium浏览器，需要一些时间。

### 3. 验证安装

```bash
# 测试Playwright是否安装成功
python3 -c "from playwright.async_api import async_playwright; print('✅ Playwright已安装')"
```

## 🔍 常见问题排查

### 问题1：找不到python3

**解决方案**：
```bash
# macOS通常python3在/usr/bin/python3
/usr/bin/python3 --version

# 或者使用Homebrew安装
brew install python3
```

### 问题2：Playwright安装失败

**解决方案**：
```bash
# 使用国内镜像
pip3 install playwright -i https://pypi.tuna.tsinghua.edu.cn/simple

# 手动安装浏览器
playwright install chromium
```

### 问题3：浏览器启动失败

**解决方案**：
```bash
# 检查浏览器是否安装
playwright install --help

# 重新安装浏览器
playwright install chromium --force
```

### 问题4：找不到搜索元素

**可能原因**：
- 页面结构变化
- 等待时间不够
- 选择器错误

**解决方案**：
1. 检查脚本中的选择器是否正确
2. 增加等待时间
3. 使用 `headless=False` 查看浏览器操作过程

### 问题5：下载失败

**可能原因**：
- 网络问题
- URL不正确
- 文件权限问题

**解决方案**：
```bash
# 检查网络连接
curl -I https://www.hkexnews.hk

# 检查输出目录权限
ls -la ./stock/hk_reports/
```

## 📝 调试模式

### 启用详细日志

修改脚本，在关键位置添加打印：

```python
# 在脚本中添加
import logging
logging.basicConfig(level=logging.DEBUG)
```

### 查看浏览器操作

脚本默认使用 `headless=False`，可以看到浏览器操作过程。

如果想后台运行，修改为：
```python
browser = await p.chromium.launch(headless=True)
```

### 保存截图

在脚本中添加截图功能：

```python
# 在关键步骤后保存截图
await page.screenshot(path=f'debug_{step}.png')
```
