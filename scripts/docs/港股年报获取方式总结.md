# 港股年报获取方式总结

## 📋 核心结论

**港交所没有官方的免费API**，所有数据获取都需要通过以下方式：

1. ✅ **爬虫方式**（当前代码已实现）
2. ⚠️ **分析网站实际API调用**（需要处理JSF框架）
3. 💰 **第三方付费数据服务**

## 🔍 当前代码已实现的方案

### 方案1：Puppeteer（浏览器自动化）⭐推荐

**文件**：`scripts/stock-reports/download_hk_reports.js`

**优点**：
- ✅ 支持JavaScript动态加载
- ✅ 可以处理复杂的表单交互
- ✅ 稳定性较好

**缺点**：
- ⚠️ 需要安装Puppeteer（体积较大）
- ⚠️ 运行速度较慢（需要启动浏览器）

**使用方式**：
```bash
node scripts/stock-reports/download_hk_reports.js \
  --code 00883 \
  --name 中国海洋石油 \
  --years 2023 \
  --type annual
```

### 方案2：HTTP POST请求（直接调用搜索接口）

**文件**：`scripts/stock-reports/download_hk_reports.js` (searchHKReport函数)

**优点**：
- ✅ 速度快
- ✅ 无需浏览器
- ✅ 资源占用少

**缺点**：
- ⚠️ 港交所使用JSF框架，需要处理ViewState等隐藏字段
- ⚠️ 可能需要维护session
- ⚠️ 如果网站改版，需要更新参数

**当前实现**：
```javascript
const postData = querystring.stringify({
  'lang': lang,
  'market': 'SEHK',
  'searchType': 1,
  't1code': 40000,
  't2Gcode': -2,
  't2code': typeConfig.category || 40400,
  'stockId': stockId,
  'from': fromDate,
  'to': toDate,
  'category': 0
});
```

### 方案3：Playwright版本

**文件**：`scripts/stock-reports/download_hk_reports_playwright.js`

**优点**：
- ✅ 比Puppeteer更现代
- ✅ 更好的等待机制
- ✅ 跨浏览器支持

### 2. 处理JSF框架的特殊要求

从HTML源码可以看到，港交所使用JSF框架，需要处理：

```html
<input type="hidden" name="javax.faces.ViewState" 
       id="j_id1:javax.faces.ViewState:0" 
       value="-5284227054209800108:-7299091110423540907">
```

**改进HTTP请求方式**：
```javascript
async function searchHKReportImproved(stockCode, year, reportType, lang = 'ZH') {
  // 1. 先访问搜索页面，获取ViewState和session
  const session = await getSession();
  const viewState = await getViewState(session);
  
  // 2. 使用获取的ViewState和session发送搜索请求
  const postData = querystring.stringify({
    'javax.faces.ViewState': viewState,
    'j_idt10': 'j_idt10',
    'stockId': stockId,
    'from': fromDate,
    'to': toDate,
    // ... 其他参数
  });
  
  // 3. 使用相同的session发送请求
  // ...
}
```

## 🔍 如何分析实际API

### 步骤1：使用浏览器开发者工具

1. 访问：https://www1.hkexnews.hk/search/titlesearch.xhtml?lang=zh
2. 打开开发者工具（F12）
3. 切换到Network标签
4. 清空请求记录
5. 填写搜索表单：
   - 股票代码：00883
   - 开始日期：2023/01/01
   - 结束日期：2024/12/31
   - 标题类别：选择"年报"
6. 点击搜索
7. 查看Network中的请求

### 步骤2：分析请求

**查看以下信息**：
- **请求URL**：实际的API端点
- **请求方法**：GET/POST
- **请求头**：需要的headers
- **请求体**：POST参数
- **响应格式**：HTML/JSON/XML

### 步骤3：提取关键信息

**可能需要的参数**：
- `javax.faces.ViewState`：JSF框架的ViewState
- `jsessionid`：Session ID
- `stockId`：股票代码（去掉前导零）
- `from`/`to`：日期范围
- `t1code`/`t2code`：类别代码

### 步骤4：实现改进版本

根据分析结果，改进HTTP请求方式，使其更稳定、更快。
