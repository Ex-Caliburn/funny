## 🛠️ 手动下载方法

**步骤**：

1. **访问披露易**：<https://www.hkexnews.hk/>

2. **搜索标题**：
   - 点击"标题搜索"或"搜索标题"
   - 输入股票代码（如：00700 代表腾讯）
   - 选择报告类型：
     - `Annual Report` - 年报
     - `Interim Report` - 中期报告
     - `Quarterly Report` - 季度报告
   - 选择时间范围

3. **下载文件**：
   - 在搜索结果中找到目标报告
   - 点击报告标题进入详情页
   - 下载PDF文件

**示例**：下载腾讯（00700）2023年年报

```

2. 搜索：股票代码 00700
```

### JSF框架说明

**什么是JSF？**

JSF（JavaServer Faces）是Java的Web应用框架，港交所网站使用JSF框架。

**JSF的特点**：

1. **ViewState（视图状态）**
   - 每次请求都需要包含ViewState
   - ViewState值会变化，不能重复使用
   - 必须与session绑定

2. **Session管理**
   - ViewState与Session绑定
   - 需要维护Cookie中的JSESSIONID
   - 跨请求需要保持同一个Session

3. **组件ID自动生成**
   - 使用冒号分隔：`j_idt10:searchStockCode`
   - ID可能变化，不能硬编码

**为什么需要特殊处理？**

- ❌ 直接发送HTTP请求会失败（缺少ViewState）
- ❌ 每次请求都需要新的ViewState
- ❌ 必须保持Session一致性

**解决方案**：

- ✅ 使用浏览器自动化（Puppeteer/Playwright）自动处理
- ⚠️ 或手动获取ViewState和Session（较复杂）

### 方案4：Python + Selenium/Playwright

**Python + Selenium示例**：

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()
driver.get('https://www.hkexnews.hk/search/titlesearch.xhtml?lang=zh')

# 填写股票代码
stock_input = driver.find_element(By.ID, 'searchStockCode')
stock_input.clear()
stock_input.send_keys('00700')

# 填写日期
from_date = driver.find_element(By.ID, 'searchDate-From')
from_date.clear()
from_date.send_keys('2023/01/01')

to_date = driver.find_element(By.ID, 'searchDate-To')
to_date.clear()
to_date.send_keys('2024/12/31')

# 点击搜索
search_btn = driver.find_element(By.CLASS_NAME, 'filter__btn-applyFilters-js')
search_btn.click()

# 等待结果
WebDriverWait(driver, 20).until(
    EC.presence_of_element_located((By.CSS_SELECTOR, 'table tbody tr'))
)

# 提取结果
results = driver.find_elements(By.CSS_SELECTOR, 'table tbody tr')
for result in results:
    print(result.text)

driver.quit()
```

**Python + Playwright示例**（推荐）：

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    
    page.goto('https://www.hkexnews.hk/search/titlesearch.xhtml?lang=zh')
    
    # 填写表单
    page.fill('#searchStockCode', '00700')
    page.fill('#searchDate-From', '2023/01/01')
    page.fill('#searchDate-To', '2024/12/31')
    
    # 点击搜索
    page.click('.filter__btn-applyFilters-js')
    
    # 等待结果
    page.wait_for_selector('table tbody tr', timeout=20000)
    
    # 提取结果
    results = page.query_selector_all('table tbody tr')
    for result in results:
        print(result.inner_text())
    
    browser.close()
```

**优点**：

- ✅ 与Node.js版本类似
- ✅ Python生态丰富
- ✅ 跨平台支持好

### 1. 股票代码格式

- **港股代码**：5位数字（如：00700）
- **A+H股**：同一公司在A股和港股都有上市，代码不同
  - 例如：中国平安 A股：601318，港股：02318

- 建议在网络稳定时使用

### 5. 数据格式

- 港股财报通常使用PDF格式
- 部分公司可能提供Excel格式的财务数据表

### 6. 报告发布时间

- 年报通常在次年3-4月发布（如2023年年报在2024年发布）
- 脚本会自动处理，搜索范围会延伸到次年年底

## 📊 港股报告类型说明

### 年报（Annual Report）

- **报告期**：1月1日 - 12月31日
- **发布时间**：次年3-4月
- **内容**：最详细的财务和经营数据
- **文件大小**：通常 5-15MB
- **类别代码**：40100

### 中期报告（Interim Report）

- **报告期**：1月1日 - 6月30日
- **发布时间**：当年8-9月
- **内容**：上半年财务和经营数据
- **文件大小**：通常 3-8MB
- **类别代码**：40200

### 季度报告（Quarterly Report）

- **报告期**：季度（Q1/Q2/Q3）
- **发布时间**：季度结束后1-2个月
- **内容**：季度财务数据
- **文件大小**：通常 1-3MB
- **类别代码**：40300

### 业绩公告（Results Announcement）

- **发布时间**：季度/年度结束后
- **内容**：简要业绩数据
- **文件大小**：通常 100KB-1MB
