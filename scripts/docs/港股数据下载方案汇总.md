## 🖱️ 方案4：手动下载（最可靠）

### 步骤

1. **访问披露易网站**
   - 网址：https://www.hkexnews.hk
   - 选择"上市公司信息标题搜寻"

2. **填写搜索条件**
   - 股票代码：00700（腾讯控股）
   - 日期范围：2023/01/01 - 2024/12/31
   - 标题类别：选择"财务报表/ESG信息" → "年报"

3. **下载PDF**
   - 点击搜索结果中的PDF链接
   - 保存到本地

### 优势
- ✅ 100%可靠
- ✅ 无需编程
- ✅ 可以验证文件正确性

## 🐍 方案7：Python + Selenium/Playwright

### 使用Selenium

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()
driver.get('https://www.hkexnews.hk/search/titlesearch.xhtml?lang=zh')

# 填写股票代码
stock_input = driver.find_element(By.ID, 'searchStockCode')
stock_input.clear()
stock_input.send_keys('00700')

# 填写日期
from_date = driver.find_element(By.ID, 'searchDate-From')
from_date.clear()
from_date.send_keys('2023/01/01')

to_date = driver.find_element(By.ID, 'searchDate-To')
to_date.clear()
to_date.send_keys('2024/12/31')

# 点击搜索
search_btn = driver.find_element(By.CLASS_NAME, 'filter__btn-applyFilters-js')
search_btn.click()

# 等待结果
WebDriverWait(driver, 20).until(
    EC.presence_of_element_located((By.CSS_SELECTOR, 'table tbody tr'))
)

# 提取结果
results = driver.find_elements(By.CSS_SELECTOR, 'table tbody tr')
for result in results:
    print(result.text)

driver.quit()
```

### 使用Playwright（推荐）

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    
    page.goto('https://www.hkexnews.hk/search/titlesearch.xhtml?lang=zh')
    
    # 填写表单
    page.fill('#searchStockCode', '00700')
    page.fill('#searchDate-From', '2023/01/01')
    page.fill('#searchDate-To', '2024/12/31')
    
    # 点击搜索
    page.click('.filter__btn-applyFilters-js')
    
    # 等待结果
    page.wait_for_selector('table tbody tr', timeout=20000)
    
    # 提取结果
    results = page.query_selector_all('table tbody tr')
    for result in results:
        print(result.inner_text())
    
    browser.close()
```

## 📝 方案8：Node.js + Playwright

### 安装

```bash
npm install playwright
npx playwright install chromium
```

### 实现

```javascript
const { chromium } = require('playwright');

async function downloadHKReports(stockCode, year) {
  const browser = await chromium.launch({ headless: false });
  const page = await browser.newPage();
  
  await page.goto('https://www.hkexnews.hk/search/titlesearch.xhtml?lang=zh');
  
  // 填写表单
  await page.fill('#searchStockCode', stockCode);
  await page.fill('#searchDate-From', `${year}/01/01`);
  await page.fill('#searchDate-To', `${year + 1}/12/31`);
  
  // 点击搜索
  await page.click('.filter__btn-applyFilters-js');
  
  // 等待结果
  await page.waitForSelector('table tbody tr', { timeout: 20000 });
  
  // 提取结果
  const results = await page.$$eval('table tbody tr', rows => {
    return rows.map(row => {
      const cells = row.querySelectorAll('td');
      return {
        date: cells[0]?.textContent,
        title: cells[3]?.textContent,
        link: cells[3]?.querySelector('a')?.href
      };
    });
  });
  
  console.log(results);
  
  await browser.close();
}

downloadHKReports('00700', 2023);
```
