## 🛠️ 手动下载方法

### 方法1：通过披露易网站下载

**步骤**：

1. **访问披露易**：<https://www.hkexnews.hk/>

2. **搜索标题**：
   - 点击"标题搜索"或"搜索标题"
   - 输入股票代码（如：00700 代表腾讯）
   - 选择报告类型：
     - `Annual Report` - 年报
     - `Interim Report` - 中期报告
     - `Quarterly Report` - 季度报告
   - 选择时间范围

3. **下载文件**：
   - 在搜索结果中找到目标报告
   - 点击报告标题进入详情页
   - 下载PDF文件

**示例**：下载腾讯（00700）2023年年报

```
1. 访问：https://www.hkexnews.hk/
2. 搜索：股票代码 00700
3. 报告类型：Annual Report
4. 时间范围：2023-01-01 至 2023-12-31
5. 找到"2023 Annual Report"
6. 下载PDF
```

### 方法2：通过公司官网下载

**步骤**：

1. 访问公司官网
2. 找到"投资者关系"（Investor Relations）或"IR"栏目
3. 进入"财务报告"（Financial Reports）或"业绩报告"
4. 选择年份和报告类型

**示例公司官网**：

## 💻 自动化下载工具

### ✅ 已实现：download_hk_reports.js

基于A股下载工具 `download_all_reports.js` 的功能，已创建港股业绩报下载脚本。

**功能特点**：

- ✅ 支持年报、中期报告、季度报告
- ✅ 支持中英文报告
- ✅ 自动搜索和下载
- ✅ 智能文件命名
- ✅ 断点续传（已下载文件自动跳过）

**使用方法**：

```bash
# 下载所有类型报告
node scripts/download_hk_reports.js --code 00700 --name 腾讯控股 --years 2023 --type all

# 只下载年报
node scripts/download_hk_reports.js --code 00700 --name 腾讯控股 --years 2024 --type annual

# 同时下载多个类型
node scripts/download_hk_reports.js --code 00700 --name 腾讯控股 --years 2023 --types annual,interim

# 下载多年数据
node scripts/download_hk_reports.js --code 00700 --name 腾讯控股 --start 2021 --end 2023 --type annual

# 指定语言
node scripts/download_hk_reports.js --code 00700 --name 腾讯控股 --years 2024 --type annual --lang ZH
```

**参数说明**：

| 参数 | 说明 | 必填 | 示例 |
|------|------|------|------|
| `--code` | 股票代码（5位数字） | ✅ | `00700` |
| `--name` | 公司名称 | ✅ | `腾讯控股` |
| `--years` | 年份（逗号分隔） | * | `2021,2022,2023` |
| `--start` | 起始年份 | * | `2021` |
| `--end` | 结束年份 | * | `2023` |
| `--type` | 报告类型（单个） | ✅ | `all` / `annual` / `interim` / `quarterly` |
| `--types` | 报告类型（多个，逗号分隔） | ✅ | `annual,interim` |
| `--lang` | 语言（ZH/EN） | ❌ | `ZH`（默认）或 `EN` |
| `--output` | 输出目录（可选） | ❌ | `./hk_reports` |

**报告类型**：

| 参数值 | 说明 | 下载内容 |
|--------|------|---------|
| `all` | 所有报告 | 年报 + 中期报告 + 季度报告 |
| `annual` | 年报 | 仅年报 |
| `interim` | 中期报告 | 仅中期报告 |
| `quarterly` | 季度报告 | Q1 + Q2 + Q3 |
| `q1` | 第一季度 | 仅Q1 |
| `q2` | 第二季度 | 仅Q2 |
| `q3` | 第三季度 | 仅Q3 |

**输出目录**：

```
stock/
└── hk_reports/
    └── 腾讯控股/
        ├── 腾讯控股_2023_年报.pdf
        ├── 腾讯控股_2023_中期报告.pdf
        └── ...
```

**注意事项**：

1. 港股代码必须是5位数字（如：00700）
2. 报告通常在次年发布（如2023年年报在2024年发布），脚本会自动处理
3. 如果搜索结果不是直接PDF链接，脚本会自动访问详情页提取PDF链接
4. 建议在网络稳定时使用，脚本已内置延迟避免过快请求

**安装Puppeteer（推荐）**：

为了支持JavaScript动态加载，建议安装Puppeteer：

```bash
npm install puppeteer
```

安装后，脚本会自动使用Puppeteer来访问港交所网站，可以获取动态加载的搜索结果。

**⚠️ 注意事项**：

1. **Puppeteer可选**：如果未安装Puppeteer，脚本会回退到HTTP请求方式（可能无法获取动态内容）
2. **首次运行**：Puppeteer首次运行时会下载Chromium浏览器（约170MB），请耐心等待
3. **网络要求**：需要能够访问 `www.hkexnews.hk`
4. **性能**：使用Puppeteer会比HTTP请求慢一些，但能获取完整数据

## 🔍 港股报告类型说明

### 年报（Annual Report）

- **报告期**：1月1日 - 12月31日
- **发布时间**：次年3-4月
- **内容**：最详细的财务和经营数据
- **文件大小**：通常 5-15MB

### 中期报告（Interim Report）

- **报告期**：1月1日 - 6月30日
- **发布时间**：当年8-9月
- **内容**：上半年财务和经营数据
- **文件大小**：通常 3-8MB

### 季度报告（Quarterly Report）

- **报告期**：季度（Q1/Q2/Q3）
- **发布时间**：季度结束后1-2个月
- **内容**：季度财务数据
- **文件大小**：通常 1-3MB

### 业绩公告（Results Announcement）

- **发布时间**：季度/年度结束后
- **内容**：简要业绩数据
- **文件大小**：通常 100KB-1MB

## ⚠️ 注意事项

### 1. 股票代码格式

- **港股代码**：5位数字（如：00700）
- **A+H股**：同一公司在A股和港股都有上市，代码不同
  - 例如：中国平安 A股：601318，港股：02318

### 2. 报告语言

- 港股报告通常提供**中英文双语版本**
- 下载时注意选择需要的语言版本

### 3. 报告命名

- 港股报告命名格式可能不同
- 建议下载后统一重命名：`公司名_年份_报告类型.pdf`

### 4. 网络要求

- 访问港交所网站可能需要稳定的网络连接
- 某些地区可能需要VPN

### 5. 数据格式

- 港股财报通常使用PDF格式
- 部分公司可能提供Excel格式的财务数据表
