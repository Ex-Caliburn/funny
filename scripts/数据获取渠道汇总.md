## 📈 方案1：从定期报告中提取（推荐）

### 优势
- ✅ **最权威** - 经过审计的官方数据
- ✅ **最详细** - 包含完整的经营分析
- ✅ **最可靠** - 数据准确性有保障

### 可用报告
```bash
# 下载山煤国际2024年所有定期报告
node scripts/download_all_reports.js \
  --code 600546 \
  --name 山煤国际 \
  --years 2024 \
  --type all
```

### 数据位置
定期报告中的生产经营数据通常在以下章节：

**年报/半年报**：
- 第三节 管理层讨论与分析
  - 主营业务分析
  - 生产情况
  - 销售情况
  - 主要产品产销量

**季报**：
- 经营情况讨论与分析
- 主要经营数据

### 示例：从年报提取数据

我们已经有解析工具 `shanmei_report_parse.js`，可以自动提取：
- 煤炭产量
- 煤炭销量
- 营业收入
- 利润数据

- 2025年开始发布独立的季度生产经营数据公告
- 2024年及之前，数据主要在定期报告中披露
- 2022年曾短暂发布过月度数据，后停止
