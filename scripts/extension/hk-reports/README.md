# 港股业绩报自动下载扩展

在港交所披露易（HKEX News）搜索页面自动填写表单、搜索并下载业绩报的Chrome扩展。

## 功能特性

- ✅ **自动填写股票代码**：输入代码后自动选择匹配的股票
- ✅ **自定义日期范围**：可选择开始日期和结束日期（默认最近3年）
- ✅ **自动选择文件类别**：选择"財務報表/環境、社會及管治資料" -> "所有"
- ✅ **自动搜索**：点击搜索按钮
- ✅ **自动过滤下载**：自动识别业绩报（年报、中期报告、季度报告）并下载
- ✅ **智能文件管理**：文件自动保存到 `downloads/股票代码/` 目录

## 安装方法

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本目录 `hk-reports/`

## 使用方法

1. 访问港交所披露易搜索页面：
   - 中文：<https://www1.hkexnews.hk/search/titlesearch.xhtml?lang=zh>
   - 英文：<https://www1.hkexnews.hk/search/titlesearch.xhtml?lang=en>

2. 页面右上角会出现"港股业绩报下载"控制面板

3. 在输入框中填入股票代码（例如：`00700`）

4. 选择日期范围（默认已设置为最近3年，可自定义修改）

5. 点击"填入搜索条件"按钮（蓝色按钮）

6. 扩展会自动执行以下操作：
   - 填写股票代码并选择自动完成建议
   - 设置选择的日期范围
   - 选择文件类别为"所有财报"
   - 点击搜索按钮
   - 页面会刷新显示搜索结果

7. 页面刷新后，如果检测到搜索结果，会自动显示"开始下载"按钮（绿色按钮）

8. 点击"开始下载"按钮，扩展会：
   - 提取搜索结果中的业绩报链接
   - 过滤并下载所有业绩报（年报、中期报告、季度报告）

9. 下载的文件会自动保存到 `downloads/股票代码/` 目录（例如：`downloads/00700/`）

## 使用说明

- **填入搜索条件**：填写搜索条件并提交搜索，页面会刷新（按钮一直显示）
- **开始下载**：在搜索结果页面点击，只执行下载逻辑，不会重新填写表单（有搜索结果时显示）
- 股票代码和日期会自动保存，页面刷新后会自动恢复

## 注意事项

- ⚠️ 需要在港交所搜索页面使用（`titlesearch.xhtml`）
- ⚠️ 下载速度受网络影响，请耐心等待
- ⚠️ 如果页面结构发生变化，可能需要更新扩展代码
- ⚠️ 建议在下载过程中不要关闭页面

## 支持的业绩报类型

- 年报（Annual Report）
- 中期报告（Interim Report）
- 季度报告（Quarterly Report）
- 业绩报（Performance Report）

## 技术实现

- 使用 Content Script 注入到页面
- 自动填写表单并触发搜索
- 解析搜索结果并过滤业绩报
- 使用 Fetch API 下载PDF文件
