# 统计局零售数据导出（多页批量）

- 在 `https://www.stats.gov.cn/` 站内页面右上角注入工具按钮与“批量抓取”面板。
- 支持：当前页导出、收集本页链接、粘贴链接批量抓取并合并导出为 `.xls`。

## 本地加载

1. 打开 Chrome → 扩展程序 → 管理扩展程序。
2. 右上角开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `retail-export-extension/`。
4. 访问任意统计局公报详情页，右上角浮层可用。

## 用法

- 当前页导出：定位页面中“社会消费品零售总额主要数据”的首个表格并导出。
- 收集本页链接：扫描当前列表页的详情链接，自动填充到输入框。
- 批量抓取：逐个请求链接，抓取每页首个匹配表格，按首表头合并数据行，导出 `.xls`。

## 说明

- 表格匹配基于“社会消费品零售总额”与“主要数据”等关键字，未限定年份月份。
- 合并策略：保留第一张表的表头，后续表仅合并数据行。
- 若页面结构变动导致未能识别表格，请反馈表格选择规则以便调整。
