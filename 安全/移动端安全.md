# 移动端安全

## 前言

移动端安全是前端安全的重要组成部分，由于移动设备的特殊性（触摸屏、传感器、WebView等），存在一些独特的攻击方式和防护需求。

## WebView 安全

### Android WebView 安全配置

```javascript
// Android WebView 安全配置
webView.getSettings().setAllowFileAccess(false);
webView.getSettings().setAllowContentAccess(false);
webView.getSettings().setAllowFileAccessFromFileURLs(false);
webView.getSettings().setAllowUniversalAccessFromFileURLs(false);
```

## 触摸事件安全

触摸事件劫持是一种常见的移动端攻击方式，攻击者通过覆盖透明层或重定向触摸事件来欺骗用户。

### 防范措施

```javascript
// 防止触摸事件被劫持
let lastTouchTime = 0;
let touchStartTime = 0;
let touchStartPosition = { x: 0, y: 0 };

document.addEventListener('touchstart', e => {
  const now = Date.now();
  touchStartTime = now;
  
  // 防止快速连续点击
  if (now - lastTouchTime < 100) {
    e.preventDefault();
    return;
  }
  
  lastTouchTime = now;
});

// 检测页面是否被嵌入iframe
if (window.top !== window.self) {
  document.addEventListener('touchstart', e => e.preventDefault(), true);
}
```

## 移动端安全监控

### 触摸行为监控

```javascript
class TouchMonitor {
  constructor() {
    this.touchEvents = [];
    this.suspiciousEvents = [];
  }
  
  start() {
    this.attachEventListeners();
  }
  
  attachEventListeners() {
    const events = ['touchstart', 'touchmove', 'touchend'];
    events.forEach(eventType => {
      document.addEventListener(eventType, this.handleTouchEvent.bind(this), true);
    });
  }
  
  handleTouchEvent(event) {
    const touchInfo = {
      type: event.type,
      timestamp: Date.now(),
      touches: Array.from(event.touches).map(touch => ({
        x: touch.clientX,
        y: touch.clientY,
        pressure: touch.force || 0
      }))
    };
    
    this.touchEvents.push(touchInfo);
    this.analyzeTouchEvent(touchInfo);
  }
}
```
